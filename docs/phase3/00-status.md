### 要因分解(数字合わせはしていない)
1. **検出定義差(支配的)**: 本作の「検出候補」(G−W3 / G−W4 で ≥3σ 超過)は **γ に依存しないクラス**(凍結 §2: 既超過 → 判定不能)。一方 Hephaistos の「DS 領域内」は **(γ, T) ごとのモデル領域に観測点が入るか**で、0.2 等級の軽い超過は γ = 0.9(数等級の超過)と整合しない。定義 A は候補 3,304 星を全 γ で適合に数えるため、γ が大きいほど比が爆発する(93 / 982)。γ = 0.1 でも候補が 85% を占める。
2. **基盤差**: EDR3 vs DR2 で母集団 0.70 倍、RUWE<1.4 の追加、WISE 非同定星の除外(公刊は best-neighbour のある星のみ — 同等)。比への影響は高々 1.4 倍程度で、1 を説明しない。
3. **上限星の扱い**: 公刊は S/N<2 上限で「DS モデルが上限を下回れば適合」。本作定義 A では上限星は θ=0 → 適合(γ=0.1 で 566 星)。同方向。
4. **小数統計**: 公刊の γ = 0.9 は 4.8 星相当、γ = 0.5 は 50 星相当。比の判定は Poisson 揺らぎに敏感。

### 診断(採用せず、付議材料): 定義 B「観測残差が (γ, 300 K) モデル残差と kσ_tot 以内で整合(W3・W4 とも)、上限星は DS 流束 < 3.5σ なら整合」— 凍結成分(k=3、σ_tot、モデル、軌跡)のみ使用

定義 B は γ = 0.1 で公刊と整合するが、γ = 0.5 で 0.17(6 星 vs 期待 ~36 星)。本作の整合条件(両帯・星ごと σ)は Hephaistos の CMD 領域判定(モデル軌跡の幅、4 図)より厳しい可能性がある。

## 3.3 G3(iii) — 太陽系自己検定(T-R3)— **合格**

再現: `python3 scripts/g3_iii_solar_selftest.py`(出力 `data/phase3/g3_iii.json`)。仮想行: 太陽系を d = 1.3〜10.8 pc の 24 点格子(1.3 / 2 / 4 / 6 / 8 / 10.8 pc を含む)、GBT L + GBT S + Parkes 10-cm の 3 受信帯・軸上・各 1 観測行、EIRP_peak = 10¹¹ W(クラス上端)。凍結式 eps-v0.2 をそのまま使用。

| d [pc] | Θ_sens(L, S, P) | Λ(周辺化) | Λ(f_ill = 10⁻²) | Λ(f_ill = f_pipe = 1 の極) | 合否 |
|---|---|---:|---:|---:|---|
| 1.3 〜 4.8 | (1, 1, 1) | 0.999085 | 0.99479 | **0.0851** | 合格 |
| 5.3 〜 10.8 | (1, 1, 0) | 0.999402 | 0.99660 | 0.3617 | 合格 |

- 判定(凍結 §5): 全 d で Λ(f_ill 上端 10⁻²) ≥ 0.99 かつ Λ(周辺化) ≥ 0.999 → **合格**(最小値 0.99479 / 0.999085)。事後 P(占有) @π=10⁻² = 0.00999 ≈ 事前。
- 赤信号動作確認(合格条件ではない): f_ill = f_pipe = 1 の極で Λ = 1 − 2.15/2.35 = 0.0851 < 0.5(d ≤ 4.8 pc、3 帯とも感度内)→ 地球は「検出される」。ε(検出器)は生きており、T-R3 で事後 ≈ 事前になるのは照射因子(間欠・指向)が小さいためである。Parkes 10-cm は d > 5.24 pc で感度外(9.1e12 × (d/50)² > 10¹¹ W)、GBT は 10.9 pc まで。
- **解釈文(論文用の種)**: 「地球級帯 T-R3 では事後 ≈ 事前 — 本アトラスが空き度を語れる技術帯の下限は地球自身で校正される。」
