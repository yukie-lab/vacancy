## 1. 技術帯集合と条件節(第3条1項、裁定 #1)

- T-R1: 狭帯域(δν = 1 Hz)・連続送信、EIRP ≥ 1.0 × 10¹³ W。ν ∈ [1.10, 3.45] GHz 一様。視線加速度は turboSETI ±4 Hz/s の探索域内(|a| ≲ 10 a_⊕ 相当、または補償済み)。
- T-R2: 同上、EIRP ≥ 1.0 × 10¹⁷ W。
- T-R3: レーダー型間欠漏洩、EIRP_peak = 10¹¹ W(クラス上端で評価)、照射因子 f_ill = f_duty·f_beam ∈ [10⁻⁵, 10⁻²] 対数一様。**f_ill は星単位の潜在変数**として周辺化する(送信機側の幾何であり観測者方向は固定。観測行ごとに独立に引くと複数観測で照射が独立に当たる扱いになり、空き側に倒れる — 差し戻し #2 修正 1)。台帳値は周辺化値(13 点対数格子)。
- T-W1: 部分ダイソン球型廃熱(灰色吸収・黒体再放射)、γ ≥ 0.1(台帳に γ = 0.5, 0.9 を併記)、T_DS ∈ [100, 700] K 対数一様(20 区間)。**情報列(帯定義外)**: γ = 0.01 の θ₃·θ₄ を台帳に併記する(`info_eps_W1_g0.01`)。T-W1 の帯定義(γ ≥ 0.1)は不変であり、γ = 0.01 列は空き度の主張に用いない(差し戻し #2 修正 4、凍結前に書き込み)。

## 3. 合算式(第3条3–5項)

```
電波: 1 − ε^rad_i(T) = Σ_c w_c Π_{s∈rad(i)} [1 − ε_{s,i}(T)·1[c ⊂ B_s]]      (c: 共通 ν 区間、w_c = 幅/2.35)
T-R3: 1 − ε^rad_i(T-R3) = Σ_f w_f Σ_c w_c Π_{s∈rad(i)} [1 − Θ_s f_pipe f · 1[c ⊂ B_s]]   (f_ill は星単位の潜在変数、対数一様事前 [10⁻⁵, 10⁻²]、13 点格子で周辺化。第3条5項の潜在変数集合に f_ill を追加)
      f_ill の全共有は保守的宣言である(真の構造は f_beam 共有・f_duty 部分独立の中間にあり、Jensen の不等式より全共有は ε を下界側に置く。すなわち検出力を過小申告する側であり、占有を除外できない方向に倒れる)。
廃熱: 1 − ε^mir_i(T-W1) = (1/20) Σ_T (1 − θ₃(T))(1 − θ₄(T))
Λ_i(T) = 1 − ε^m_i(T)                  (v1: 各帯は単一モダリティ)
P(占有 | D, T, π) = expit( logit π + ln Λ_i(T) )、π ∈ [10⁻⁶, 0.5] 対数 51 点、代表 π = 10⁻³, 10⁻², 10⁻¹
```

## 5. G1–G3 合格基準

- **G1 単調性**: 全星・全帯で、観測行を 1 つずつ加えた Λ の列が非増加(許容 +10⁻¹²)。違反 0 件で合格。**安定性**: log₁₀ Λ の 90% 区間幅 > 0.5 dex の星を「低信頼セル」として列挙(合否ではなく報告義務)。
- **G2 二経路**: 参謀が台帳(ε 行・区間重み)から対数和で Λ を再計算。全星・全帯で |Δ log₁₀ Λ| ≤ 10⁻⁶。不一致は係数で合わせず、両経路を再導出(第10条5項)。
- **G3(i)(a) — 報告義務(合否判定なし)**: Price+20 §5.3 の公刊値 0.45% / 0.37% / 2.0%(GBT L / GBT S / Parkes、N = 882 / 1005 / 189)と、当方の明示的算式 **二項厳密 95% 上限: f = [1 − 0.05^{1/N}] / P、P(検出|占有) = f_pipe = 0.5** による値の比較表を報告する。脚注: 原典の算式は本文に明記されていない(「P = 0.5、各星を試行、95% 信頼」のみ)。公刊三値を逆算すると f·N = 3.97 / 3.74 / 3.78 でばらつき、単一の標準式(4/N、ポアソン 2.996/(0.5N)、二項厳密)では三値同時に再現できない(参謀照合済み)。よって逐語再現は合格基準にしない。
- **G3(i)(b) — ハードゲート(一本化)**: WS20 §3.1 の ≤50 pc「≲0.0660%」= **1/N、N = 1513**(本作の WS20 表再計数 1,513 と完全一致、Phase 0 実査で確認済み)を基準とする。≤100 pc 0.061%(EIRP ≳ 6.5 × 10¹³ W)・≤200 pc 0.039%(≳ 2.5 × 10¹⁴ W)は同じ 1/N で N を再計数し **±1% 以内**で合格。**距離基盤(確認 1)**: 再計数は WS20 表の `rest` 距離(DR2 基盤、Bailer-Jones+18)で行う。EDR3/GCNS 距離は G3(i) では使用しない(基盤差の混入防止)。
- **G3(i)(c)**: 本作の星単位ベイズ上界の周辺化(Σ_i Λ_i/N 等)は別量であり、(a)(b) との差を表で明示し一致を強要しない(第7条 G3(i))。
- **G3(ii)**: Hephaistos I Table 1(100 pc: 265,724 星、γ = 0.1/0.5/0.9 で 6.6e-3/1.9e-4/1.8e-5)を、GCNS 主系列 + 本作の超過判定で計数し、**各 γ で桁一致(比 0.3–3)**。DR2/EDR3 基盤差による残差は表で明示。
- **G3(iii)**: 太陽系を d = 1.3–10.8 pc の仮想行(GBT L + GBT S + Parkes 10-cm の 3 受信帯、軸上、各 1 観測行)として T-R3 に通し、f_ill 区間上端 10⁻² でも Λ ≥ 0.99(事後 ≈ 事前。周辺化値では Λ ≥ 0.999)。f_ill = f_pipe = 1 の極では「検出される」(Λ = 1 − 2.15/2.35 ≈ 0.085 < 0.5)ことを赤信号の動作確認として併記。

## 6. ホールドアウト(第9条4項)— ★ 1.5 **裁定 #2 で不採用確定**

判定不能率の確定値(電波 99.52%、廃熱 42.16%)を踏まえ、**不採用**(裁定 #2、手続き完了)。理由: 電波帯の可判定星は 1,587 星で、二分すると G3(i) の距離殻再計数(N が数百)の統計が崩れる。廃熱帯は全天一様なので二分の意味が薄い。
