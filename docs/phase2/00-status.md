- 廃熱の低信頼セルの **97%(25,113 / 25,822)は「片側が Λ = 0」**: θ が離散(0/1)で、摂動により T_DS 区間の 1 つが検出/非検出を行き来すると Λ が 0 ↔ 0.05 を跳び、log₁₀ Λ は −15(クリップ)↔ −1.3 となって幅が爆発する。事後で見ると π = 10⁻² で 10⁻¹⁷ ↔ 10⁻³ の違いであり、「占有確率 ≲ 10⁻³」という結論は全セルで不変。**これは凍結指標の定義どおりの報告であり、指標は変更しない**(変更は逸脱)。論文では低信頼セル列挙と併せて「事後での実効幅」を参考列として示す(Phase 5 で付議)。
