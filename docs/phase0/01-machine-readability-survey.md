## 2. 細目

### 2.1 WS20 表の検証
- EIRP_min 再計算: `EIRP = EIRP50(inst) × (d/50 pc)² / exp(−4 ln2 (θ/FWHM)²)`、EIRP50 = 2.1e12 W(GBT L/S)、9.1e12 W(Parkes 10-cm)で **356,616 行すべて比 1.0000**(5–95% 分位 0.99999–1.00001)。表の来歴(Price+20 §5.2 + ガウス応答)は完全に閉じる。
- 構成: GBT L 210,146 行 / GBT S 89,654 / Parkes 56,816。同一星が複数ポインティング・複数受信帯に現れる(356,616 行 / 288,315 星)。
- 距離分布: ≤50 pc 1,513 星、≤100 pc 1,671 星、残り ~287k 星は 100 pc 超の背景星(≤1 kpc)。
- EIRP_min ≤ 1e13 W(T-R1 で感度因子 1): 1,626 星。EIRP_min ≤ 1e17 W(T-R2): 278,577 星。
- `BP-RP` 欠損 6.8%(ε には不要)。

### 2.2 DR2 → EDR3 照合の内訳(≤100 pc 1,671 星)
- 位置照合(固有運動で 2015.5→2016.0 補正、1″、|ΔG|<0.5): 1,534 星一致(分離中央値 0.0″)。
- 不一致 137 星: GCNS 内に 30″ 以内の対応星が無いものが 116 星。これらは **G 2–9 等の明るい星**(固有運動中央値 92 mas/yr)で、EDR3 で解が落ちた明るい星が主因。GCNS `missing` 表(Simbad 位置・視差)で 30″・|Δplx|<3 mas により **43 星**を回収可能。残 ~94 星は Phase 1 で個別に扱う(DR2 側の偽解・連星分離の可能性)。
- 照合率はいずれの距離上限でも失敗状態閾値 80% を上回る。

### 2.3 BL アーカイブの観測ログ
- 取得済み全目標で MJD・中心周波数・望遠鏡・座標が存在(100%)。取得数・帯別目標数・年別ファイル数は **§4 統一表**(`scripts/bl_log_stats.py` の出力)のみを正とし、本文には重複記載しない(裁定 #1 差し戻し対応)。
- ファイル中心周波数は分割サブバンドごとに記録されるため、受信帯への帰属は暫定(名目)。Phase 1 で BL のノード命名規約により機械化する。
- C/X 帯・Parkes UWL は **未公刊**(Price+20 は L/S/10-cm のみ)。上限が公刊されていない観測は、観測事実のみ来歴に残し、ε は第2層扱い(本文・図からの抽出に相当する前提復元が必要)→ v1 は判定不能(第5条1項 d)。

### 2.4 GCNS の WISE 欄の性格
- VizieR 版 GCNS の W3/W4 は「等級あり・誤差なし」の行が多い(W3: 250,376 − 209,535 = 40,841 行、W4: 250,451 − 66,904 = 183,547 行)。AllWISE 規約ではこれは **2σ 上限値**(非検出)である。T-W1 の Θ_det はこの区別をそのまま使う(検出星は超過判定、非検出星は「DS 込み予測等級が上限より明るいか」)。
- Hephaistos 主系列選択(式 8–9 + RUWE<1.4)を GCNS に適用: 231,520 星(巨星除外 1,682、白色矮星・高励起除外 39,102)。うち W3∧W4 S/N≥3.5 は 29,248 星。Hephaistos I の 100 pc 母集団 265,724 星(DR2 基盤、非検出は上限で処理)と桁が合う。

### 2.5 他に見つかった機械可読の候補(拡張区画の棚)
- VizieR: Harp+16 ATA(`J/AJ/152/181`)、Siemion+13 KOI(`J/ApJ/767/94`)、Zuckerman+24 BL(`J/AJ/167/20/table1`)、Nilipour+23(`J/AJ/166/79`)。いずれも v1 第1層には含めず、Phase 5 の拡張区画注記に列挙。

## 3. 失敗状態の判定
- 第1層の星・source_id 照合率 < 80% → **非該当**(最低でも 91.8%)。
- 帯の ε 導出式が文献から閉じない → **T-R1/R2/R3: 閉じる**(WS20 再計算で検証済み)。**T-W1: 導出式は閉じるが「既存上限」ではない** → 第6条の文言との整合を ★ 裁定に付す(`02-…-design.md` §5 A)。
