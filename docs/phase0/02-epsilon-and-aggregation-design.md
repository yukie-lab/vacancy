## 2. ε 導出式(帯ごとに 1 本)

記法: 星 i、観測(サーベイ要素)s、技術帯 T。各因子は [0,1]。

### 2.1 T-R1 / T-R2(電波・連続・等方)

観測 s は「望遠鏡 × 受信帯 × 観測エポック(カデンス)」を単位とする(Price+20 の 1 カデンス = 3 × 300 s ON)。

```
ε_{s,i}(T-Rk; ν) = Θ_sens(s,i,T-Rk) · 1[ν ∈ B_s] · f_pipe(s) · f_duty(T-Rk) · f_drift(T-Rk) · f_beam(T-Rk)
```

各因子:

1. **感度・距離 Θ_sens** = 1[ EIRP_min,s,i ≤ EIRP_T ]。クラスの**最弱成員**(閾値ちょうど)で評価する = 保守側(空き側に倒さない、第5条3項)。
   `EIRP_min,s,i = 4π d_i² F_min,s / R_s(θ_i)`、`F_min,s = S_min,s · δν`(δν = 1 Hz、Price+20 §5.2)、
   `R_s(θ) = exp(−4 ln2 (θ/FWHM_s)²)`(WS20 §3 のガウス応答)。
   原典値: 50 pc・軸上で GBT L/S = 2.1 × 10¹² W、Parkes 10-cm = 9.1 × 10¹² W(Price+20 §5.2、SEFD 10 Jy / 34 Jy、S/N ≥ 10、t_obs 300 s)。
   **検証済み**: WS20 表の min-detec-EIRP 全 356,616 行をこの式で再計算し、比の中央値 1.0000(5–95% 0.99999–1.00001)。ε_sens はそのまま輸入できる。
   距離は WS20 の `rest`(Bailer-Jones 型推定)→ Phase 1 では GCNS の dist_50 に差替え(EDR3 基盤統一)。MC 摂動: d の 16/84 分位、SEFD ±20%†。
2. **帯域被覆 1[ν ∈ B_s]**: B_s は受信帯からノッチを除いた区間。GBT L = [1.10,1.20]∪[1.34,1.90]、GBT S = [1.80,2.30]∪[2.36,2.80]、Parkes 10-cm = [2.60,3.45] GHz(Price+20 §2.3–2.4)。ν は潜在変数で、合算時に窓 [1.10,3.45] GHz 上で周辺化する(§3)。
3. **パイプライン/RFI 因子 f_pipe** = **0.5**(Price+20 §5.3 が RFI 遮蔽を考慮して採った 1 観測あたり検出確率。彼らの上限値はこの値で算出されているので、G3(i) の同一前提に必須)。MC 摂動: [0.3, 0.8]†。
4. **稼働率 f_duty** = 1(T-R1/R2 は連続送信クラスと宣言。「非定常送信機は本帯の対象外」と条件節に明記)。
5. **ドリフト被覆 f_drift** = 1。根拠: turboSETI 探索範囲 ±4 Hz/s(Price+20 §3)は、地球型自転加速度(0.034 m/s² → 1.5 GHz で 0.17 Hz/s、3.45 GHz で 0.39 Hz/s)を十分に含む。クラス定義に「送信機の視線加速度 |a| ≤ 10 a_⊕ 相当、または太陽系重心に対し補償済み」を含める。MC 摂動: Sheikh+19 の系外惑星ドリフト分布を用いた感度枠(0.5–1)†。
6. **ビーミング f_beam** = 1(等方クラス)。

### 2.2 T-R3(地球級漏洩・自己検定帯)

同じ骨格で、クラス宣言を変える:

```
ε_{s,i}(T-R3; ν) = Θ_sens(s,i; EIRP_peak) · 1[ν ∈ B_s] · f_pipe(s) · f_duty(T-R3) · f_drift · f_beam(T-R3)
```

- EIRP_peak = 10¹¹ W(クラス上端で評価 = 検出側に寄せた**厳しい**自己検定。上端でも「事後 ≈ 事前」なら下端は自明)。
- 【裁定 #1 F】照射因子 f_ill = f_duty·f_beam は単一値ではなく、宣言区間 [10⁻⁵, 10⁻²](対数一様)を MC で掃引する(典拠: Sullivan, Brown & Wetherill 1978; Saide+23 MNRAS 522, 2393)。条件節に「レーダー型間欠送信」を明記。放送型漏洩(EIRP ~10⁶ W 級)は帯の下限外 → 判定不能。
- 期待: 太陽系を d = 1.3–5 pc に置いた仮想台帳行で、EIRP_min(GBT, 1.3 pc) = 2.1e12 × (1.3/50)² ≈ 1.4 × 10⁹ W ≤ 10¹¹ W → Θ_sens = 1 になる星が近傍に存在する。よって **T-R3 の ε は f_ill·f_pipe ∈ [5 × 10⁻⁶, 5 × 10⁻³]** に落ち、Λ ≈ 1 −(10⁻⁵〜10⁻²)、事後 ≈ 事前。これが G3(iii) の「校正値」(地球自身は検出されない)になる。もし f_duty = f_beam = 1 で評価すれば地球は「検出される」と出る — それは ε の過大評価の赤信号として正しく機能する(PHASES 3.3)。

### 2.3 T-W1(廃熱)

観測 s = WISE(AllWISE/CATWISE、全天 1 回)。GCNS 内蔵の W1–W4 等級と誤差を用いる。

```
ε_{WISE,i}(T-W1; γ, T_DS) = Θ_det(i) · Θ_excess(i; γ, T_DS) · f_duty(=1) · f_beam(=1)
```

1. **検出性 Θ_det(i)**: 星 i が W3 **かつ** W4 で S/N ≥ 3.5 の検出を持つ(Hephaistos II §2.6 の採用閾値)。持たない星は、DS 込みの予測 W3/W4 等級が AllWISE 5σ 検出限界(W3 ≈ 11.3 mag†、W4 ≈ 8.0 mag†; Cutri+14)より明るくなる場合に限り Θ_det = 1(「あれば検出されていた」)。どちらでもない星は判定不能(第5条1項a — 視野内だが感度外)。
2. **超過判定 Θ_excess(i; γ, T_DS)**: Hephaistos の合成モデル(式 1–3: `m = −2.5 log(10^{−m★'/2.5} + 10^{−m_DS/2.5})`, `m★' = m★ − 2.5 log(1−γ)`, DS は温度 T_DS の黒体、L_DS = γ L★)で星 i の (G−W3, G−W4, M_G) を DS 込みに変換し、主系列軌跡(GCNS から経験的に構築、色ビンごとの中央値と散布 σ_locus)から
   `Δ = |c_model − c_locus(M_G)| / sqrt(σ_phot,i² + σ_locus²) ≥ k`(k = **3**、感度枠 k=5)が W3 **または** W4 色で成立すれば 1。
   L★ は FLAME または M_G からの多項式(Hephaistos I 付録 B)†。
3. 潜在変数 T_DS は §3 の窓で周辺化。γ は帯閾値(0.1)で評価(最弱成員 = 保守)。
4. **既に超過を示す星**(観測色が DS 適合領域に落ちる星)は「不検出 D」が成立しないので台帳では **「検出候補(自然起源未分離)」= 判定不能** と記す(空き 0 でも 1 でもない。第5条3項)。その計数が G3(ii) のアンカー(Hephaistos I Table 1 の計数再現)になる。

## 3. 合算数理の仕様(0.3)

### 3.1 潜在変数と「併合」規則(第3条5項の精密化)

電波帯では送信周波数 ν が全観測に共通の未知量であるため、サーベイ間の単純積 Π_s(1−ε_s) は**検出確率を過大評価する**(例: 同一帯域を 2 回観測、各 ε = 0.5·p で p=1 のとき、積形 = 0.25、厳密 = 0.5)。過大評価は「空き側に倒す」誤りなので禁止(第5条3項)。

よって、**同一モダリティ内の観測は、潜在変数で周辺化した 1 本の ε に併合**してから合算する:

```
1 − ε^rad_i(T) = ∫ p(ν) Π_{s∈rad} [1 − ε_{s,i}(T; ν)] dν        (ν: 窓上一様、区分定数なので有限和)
1 − ε^mir_i(T) = ∫ p(T_DS) [1 − ε_{WISE,i}(T; γ_0, T_DS)] dT_DS
Λ_i(T) = Π_{m∈{rad, mir}} (1 − ε^m_i(T))                           (第3条3項の積はモダリティ間)
```

v1 では各帯に関与するモダリティは 1 つなので Λ_i(T-Rk) = 1 − ε^rad_i、Λ_i(T-W1) = 1 − ε^mir_i。
帯域境界で窓を分割した区間(L のみ / L∩S / S のみ / S∩P / P のみ / ノッチ)ごとに積をとり、幅で加重する。
【裁定 #1 C で義務化、憲法 v0.3 第3条5項】周辺化の共有単位は**モダリティ全体**(WS20 と BL アーカイブの観測は同一の ν を共有。サーベイ単位の周辺化は不可)。Phase 1 では潜在 ν の離散化区間をモダリティ全体で共通のグリッドにする。

G1 単調性: 観測を追加すると各 ν で Π(1−ε) は非増加 → 積分も非増加 → Λ 非増加。機械検査は「観測を 1 つずつ加えた Λ の列が非増加」で行う。

### 3.2 数値安定化

- 全て対数で計算: `log Λ = log Σ_c w_c exp(Σ_{s} log1p(−ε_{s,c}))`(c: 潜在区間、logsumexp)。
- ε は [0, 1 − 10⁻¹⁵] にクリップ。Λ ∈ [10⁻¹⁵, 1]。
- 事後: `logit P(占有|D,T,π) = logit(π) + log Λ_i(T)`。expit で評価(アンダーフローなし)。

### 3.3 π 掃引

- 対数格子 π ∈ [10⁻⁶, 0.5]、51 点。代表 π = {10⁻³, 10⁻², 10⁻¹} を台帳に併記(第3条4項)。
- 出力は「上界曲線」P(π)。単一数値の「空き度」は出さない(第10条1項)。

### 3.4 MC 摂動(G1 安定性)

- §2.4 の摂動列を独立に N = 1,000 回サンプル(seed 固定)。星 × 帯ごとに log Λ の 5/50/95 分位を保存。
- 安定性指標: 90% 区間幅 Δ(log₁₀ Λ) の分布と、「区間幅 > 0.5 dex」の星の割合(= 低信頼セル、EMBARK の低信頼セル列挙方式を継承)。

### 3.5 G2 の突合仕様

- Code は台帳 JSON に、星 × 観測 × 潜在区間の ε と区間重み w_c を**そのまま**書き出す。参謀(チャット Claude)は同じ表から対数和で Λ を再計算する。
- 許容差(案): |Δ log₁₀ Λ| ≤ 10⁻⁶(同一入力・同一式なので丸め差のみが許される)。全星・全帯。不一致は係数で合わせない(第10条5項)。

### 3.6 G3 アンカー(計数版)の定義

- (i) Price+20 §5.3: 各受信帯で「観測星数 N、検出 0、1 観測あたり検出確率 0.5」→ 0.45%(GBT L, N=882)、0.37%(GBT S, N=1005)、2.0%(Parkes, N=189)。**算式の逆算**: 0.45% = 2/(0.5 × 882) に一致 — 彼らの「95%」は上限事象数 2(≈2σ)の近似であり、二項厳密 95% 上限 `1 − 0.05^{1/N}/0.5` = 0.34%(N=882)より緩い。S 帯は 2/(0.5×1005) = 0.40% で本文 0.37% と僅差(N の定義差か。参謀照合)。本作の計数版は (a) 彼らの算式(μ=2)で逐語再現し、(b) 二項厳密値を併記する。WS20 §3.1 の ≤50 pc「≲0.0660%」は **1/N(N = 1513)** — f_pipe も Poisson 係数も含まない別算式(Phase 1 で確認、本作の再計数 1,513 と一致)。距離殻ごとの N を WS20 表から再計数して再現。
- (ii) Hephaistos I Table 1(100 pc): N = 265,724、DS 適合星の割合 6.6e-3 / 1.9e-4 / 1.8e-5(γ = 0.1/0.5/0.9, 300 K)。本作は GCNS の主系列選択(同論文式 8–9: `M_G < 4 ∧ M_G < 7(BP−RP) − 3` を巨星除外、`M_G > 3(BP−RP) + 5` を白色矮星・高励起除外)と §2.3 の適合判定で計数し、桁一致を確認する。**憲法第7条 G3(ii) の「Ĝ の個別星上限」は存在しないため、アンカーを Hephaistos I 母集団上限に置換する ★ 裁定事項 D。**
- (iii) 太陽系 T-R3: §2.2。

## 4. 判定不能の見込み(Phase 1 失敗状態の先行警告)

- GCNS 331,312 星のうち、WS20 で電波観測の視野内にある星は **1,671 星(≤100 pc)**、EIRP_min ≤ 10¹³ W(T-R1 で Θ_sens = 1)の星は **1,626 星**。すなわち母集団を GCNS 全体にとると T-R1 帯の判定不能(a)は **≈ 99.5%**。
- T-R2(10¹⁷ W)では WS20 の 278,577 星で Θ_sens = 1 だが、その大半は 100 pc より遠い背景星(WS20 の星は ≤1 kpc)。GCNS 内では同じ 1,671 星。
- T-W1 は全天サーベイなので GCNS 全星に ε を付けられる(W3/W4 検出の有無で Θ_det が分かれる。比率は GCNS 取得後に実測)。
- → PHASES Phase 1 失敗状態「判定不能 > 50%」は電波帯で**確実に発生する**。母集団定義(GCNS 全体か、観測済み星か)は ★ 裁定事項 E として先行付議する(§5)。

## 5. ★ 裁定事項(Phase 0 分岐で付議 → 裁定 #1 で A–F 確定。以下は付議時の原文)

A. **T-W1 の性格**: 既存上限の輸入ではなく、既存データ(GCNS 内蔵 WISE)+ 文献基準からの本作導出を第1層に含めるか。含めない場合 T-W1 は拡張区画(判定不能)に降格し、v1 は電波 3 帯のみになる。— 推奨: 含める(導出式は文献から閉じる。第6条第1層の文言を「機械可読の既存上限、または機械可読の既存データから文献基準で閉じる導出」に改める)。
B. **電波窓** [1.10, 3.45] GHz 一様 — 推奨どおりか、他(1–10 GHz 対数一様)か。
C. **併合規則**(§3.1)の解釈確認: 第3条5項の一般化として潜在変数周辺化を採ること。
D. **G3(ii) の置換**: Ĝ 個別星上限 → Hephaistos I Table 1 計数再現。
E. **母集団**: GCNS 全体(判定不能 ≈99.5% を主結果として報告)か、電波観測済み星に限定するか。— 推奨: GCNS 全体(第5条2項の精神。「空き度が語れる星は近傍の 0.5%」自体が測量結果)。
F. **T-R3 宣言値**(f_duty, f_beam)の文献照合を参謀に委任。

以上の裁定後、事前登録 (a)(因子構造)をコミットハッシュで固定する(0.6)。
