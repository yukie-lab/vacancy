## 2. 必須 UI(実行指示 5.3)

| 要素 | 仕様 |
|---|---|
| バナー(常時) | 「測量であって証明ではない / This is a survey, not a proof」+「空き度は入植許可証ではない / Not a settlement permit」。閉じられない |
| 条件節パネル(常時) | 現在の表示条件を文で表示: 「T-R1(EIRP ≥ 10¹³ W、ν ∈ [1.10, 3.45] GHz 一様、連続送信)の設備に関して、サーベイ集合 S = {WS20: GBT L, GBT S, Parkes 10-cm} のもとで、事前 π = 10⁻² のとき」。帯・π を変えると文が変わる |
| π スライダー | 対数 [10⁻⁶, 0.5]、既定 10⁻²。スライダー脇に「事後 = expit(logit π + ln Λ)」 |

| W1 情報レイヤ | 既定オフ。オン時は「アンカー未確立(G3(ii) 不合格、裁定 #4)」バッジを常時表示、γ 切替(0.1/0.5/0.9、0.01 は帯定義外と明示)、事後実効幅の参考列と説明文(裁定 #5-2) |
| HWC / NEA | 星詳細パネルで既知惑星・HWC 候補を表示。「照合であり合成ではない」注記 |
| 相互リンク | wake-atlas / embark-atlas への導線と、各サイトからの逆リンク(embark-atlas 側の README/リンク追記は Phase 5.4 で) |

## 3. 三次元表示(atlas3d.js 継承)
- GCNS 直交座標(pc)。主張帯の星を彩色、判定不能星は灰色点群(LOD で間引き表示、計数は凡例に全数)。
- 太陽位置に「T-R3 自己校正: d ≤ 10.8 pc、Λ ≥ 0.999」の注記。
- EMBARK 到達星は輪郭/リングで重畳(彩色の合成はしない)。

## 4. 検証ハーネス(入口)
- ブラウザ内: MANIFEST の sha256 照合(SubtleCrypto)、sim_display と lambda_ledger の代表 π 事後の一致(抜き取り ≥ 200 星、|Δ| ≤ 10⁻⁹)、計数三つ組(ok 1,554/1,587/159、判定不能 330,984、EMBARK 結合 14,799、交差 815/108/311)、凡例四文の機械取込確認、W1 既定オフの確認、ランキング UI 不在の静的検査。
- ヘッドレス: `node tools/harness_node.js`(embark-atlas の 34 項目系譜を継承・置換)。
