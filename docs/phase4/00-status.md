## 4.3 交差表示「行ける × 空いている(T 帯条件付き)」

## ★ 付議(Phase 5 に向けて)
1. **シミュレータの形態**: wake-atlas 第三面(空き度レイヤ)として統合(PHASES 5.3 の原案)か、EMBARK 同様の独立サイト(`vacancy-atlas`)か。EMBARK は独立サイト(裁定 #19)だった。
2. **事後実効幅の参考列**: G1 低信頼セル(W1)は Λ=0 クリップ由来が 97%。電波 3 帯では低信頼 0 のため v1 の主張帯には影響しないが、情報レイヤ W1 の表示で「事後実効幅」参考列を併記するか。
3. **W1 情報レイヤの表示**: シミュレータ・アトラスで「アンカー未確立(G3(ii) 不合格、裁定 #4)」の注記を常時表示する前提で、レイヤを表示する/しない。
4. **アトラス JSON の容量**(142 MB): 公開用に Phase 5 で表示専用派生(EMBARK の sim_display 方式、ビット列・判定不能星の圧縮)を作るか。
5. **EMBARK 母集団外 22,699 星**(100 pc 超)の扱い: 本アトラスの母集団外として注記のみ(推奨)。
6. **NEA / HWC の取得日・版**(2026-08-23 取得、sha256 記録済み)の凍結方法: 公開時に同一ファイルを成果物に同梱(推奨)。
7. 論文の解釈規律節に「HWC 照合表は合成ではない」「空き度は入植許可証ではない」を明記(第1条4項・第10条6項)。
